# Readable code

- Follow the project's existing conventions.
- Use descriptive variable and function names.
- Add comments explaining business rules, non-obvious
  decisions, assumptions and workarounds.
- Avoid comments that simply repeat the code.
- Update relevant comments when changing behaviour.
- If existing code is unclear, understand its purpose
  before adding explanatory comments.
